# AGENTS.md — Rohit Builds

Instructions for AI coding agents working in this repository. Read `README.md`, `BRAND.md`, and `docs/SITE-STRUCTURE.md` before making changes.

## Project context

- Personal brand portfolio: "Rohit Builds". The home page is the careers/portfolio page; passion projects (News, Shop as flagship; education system, courses, tools as supporting) each live on their own page. `/portfolio/` is a redirect to `/`.
- Astro 7 static site, NO backend. Output is `./dist/`, published to GitHub Pages via the `gh-pages` branch.
- Brand rules are mandatory: site name is always "Rohit Builds". Old branding ("Education Reimagined", "RBPN") is retired and must never reappear in copy or code.

## Development

Always start the dev server in background mode:

```
astro dev --background
```

Manage it with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Commands

| Command | Use |
| :--- | :--- |
| `npm install` | Install dependencies |
| `npm run dev` | Dev server (use `astro dev --background`) |
| `npm run build` | Build to `./dist/` |
| `npm run preview` | Preview production build |
| `npm run astro check` | Validate the project |

## Layout

- `src/pages/` — Astro route files. File path = route.
- `src/content/pages/*.html` — long-form page content, imported into Astro pages with `?raw`.
- `src/content/news/*.md` — news editions, generated by the pipeline. Frontmatter: `date`, `label`, `headlines`.
- `src/content.config.ts` — content collections config. MUST stay in `src/` (not the repo root) and the news collection uses a `glob()` loader; otherwise the collection reads as empty.
- `public/` — static assets served at site root, including `/llms.txt` and `/llms-full.txt`.
- `brand/` and `BRAND.md` — brand and voice reference. Keep copy consistent with them.
- `docs/SITE-STRUCTURE.md` — page map; update it when adding/removing routes.

## Conventions

- Wrap every page in `BaseLayout title="..."` with `<Topbar slot="topbar" active="..." />` and `<Footer slot="footer" />`.
- Import raw HTML content with `?raw` and render as HTML.
- Use design tokens from `public/assets/css/brand.css`; do not invent new colors/fonts.
- No UI framework: plain HTML/CSS/JS in `.astro` files.
- Do not add comments to code unless asked.
- Do not use emojis in code or docs unless the user requests them.

## Content collections

News article frontmatter convention (kept in sync with `news_portal.py`):

```yaml
---
date: YYYY-MM-DD
label: "<edition label>"
headlines: [ "<headline>", ... ]
---
```

## Deployment

1. `npm run build`
2. Copy `./dist/` contents onto the `gh-pages` branch and push.
   The `gh-pages` branch is the GitHub Pages source; `main` is the working branch.

## Guardrails

- Never deploy secrets or keys.
- Keep the gh-pages branch deployable at all times.
- Do not push `.github/workflows/*` files — the repo does not use Actions.
- If the dev server shows page count or collection count regressions after a change, investigate before finishing.
