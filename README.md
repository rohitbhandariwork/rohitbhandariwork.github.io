# Rohit Builds

Personal portfolio of passion projects, built by Rohit Bhandari. Each project lives on its own page: an AI-powered education system for every age group, a curated AI news portal, learning tools, courses, and more.

**Live site:** https://rohitbhandariwork.github.io

## What this is

- A personal brand portfolio (static site, no backend). The home page is the careers page: "Designing data platforms that are readable, reliable, and ready to scale" — an Azure Data Engineer evolving into a platform-minded architect.
- Flagship passion projects on their own pages: News (AI news portal, editorial voice) and Shop.
- Supporting projects: the education system (5 age groups — 4-7, 8-11, 12-15, 15-17, 18+ — with age-specific courses Bot Buddies, Code Kids, Code Quest, AI Lab, Career Launcher) and standalone learning tools (Pomoflow, Flashcard, Interview, Jobtool).
- `BRAND.md` and `brand/` define brand, voice, and visual identity; `docs/SITE-STRUCTURE.md` maps routes. `/portfolio/` redirects to `/`.

## Tech stack

- [Astro](https://astro.build) (static site generator)
- Plain HTML/CSS/JS components inside `.astro` pages (no UI framework)
- [Phaser 4](https://phaser.io) for game apps
- Markdown content collections for the news portal (`src/content/news/`)
- Raw HTML content imported into pages from `src/content/pages/*.html`
- Design tokens live in `public/assets/css/brand.css` — the single source of truth for visual style

## Development

Always run the dev server in background mode:

```
astro dev --background
```

Manage it with `astro dev stop`, `astro dev status`, and `astro dev logs`.

Full Astro docs: https://docs.astro.build

## Content model

- **News articles:** markdown files in `src/content/news/YYYY-MM-DD.md` (e.g. `2026-09-17.md`), each with frontmatter `date`, `label`, and `headlines`. Generated by the news portal pipeline (`news_portal.py`). Routes are `/news/YYYY-MM-DD/`.
- **Page content:** hand-authored raw HTML in `src/content/pages/*.html`, imported into Astro pages with `?raw`. The news one-offs (`news_index.html`, `course_index.html`, `courses_index.html`) are editorials, not routes.
- **Content config:** lives at `src/content.config.ts`. The news collection uses a `glob()` loader — keep it in `src/`, not the repo root, or the collection reads as empty.

## Deployment

- Source of truth: `main` branch (this repo).
- Published site: GitHub Pages serving the `gh-pages` branch, which contains a copy of `./dist/`.
- Deploy steps: `npm run build`, then push `dist/` contents to the `gh-pages` branch.
