# Site Structure — Rohit Builds

Map of routes, source files, and content. Read this before adding or moving pages.

## Routing

Astro file-based routing: a page at `src/pages/<path>.astro` becomes `/<path>/`. Trailing-slash routes.

## Content collections

- **News (`src/content/news/*.md`)** — one file per edition, frontmatter `date`, `label`, `headlines`. Generated by the pipeline (`news_portal.py`). Collection defined in `src/content.config.ts` with a `glob()` loader.
- **Page content (`src/content/pages/*.html`)** — raw HTML imported into Astro pages via `?raw` and rendered. Files are `<route>_<segment>.html` keyed to routes. `news_index.html` is an editorial one-off, not a route.

## Navigation

Topbar order: Home, Applications (dropdown: 4-7, 8-11, 12-15, 15-17, 18+), Courses, Pomoflow, Flashcard, Interview, Jobtool, Shop, News, Contact. The home page is the portfolio, so there is no separate "Portfolio" nav item; Contact links to `/#contact`.

## Age groups

The education system splits into 5 groups, each with a course and color identity (see `brand/visual.md`): 4-7 Bot Buddies, 8-11 Code Kids, 12-15 Code Quest, 15-17 AI Lab, 18+ Career Launcher.

## Project tiers

- **Flagship:** News, Shop.
- **Supporting:** education system (applications + courses), learning tools (Pomoflow, Flashcard, Interview, Jobtool).
- **Home:** the portfolio/careers page, which links out to the projects via nav.

## Redirects

34 legacy URLs redirect to their current routes (handled in the build; `/course/` was removed). `/portfolio/` additionally redirects to `/`. Keep this list updated when routes change.

## Adding a new page

1. Create `<route>.astro` in `src/pages/`.
2. Put long-form content in `src/content/pages/<route>.html` and import it with `?raw`.
3. Wrap in `BaseLayout title="..."` and add topbar/footer slots.
4. Add the topbar link if it belongs in nav.
5. Update this file, `llms.txt`, `llms-full.txt`, and the redirect map.
6. Rebuild and redeploy the `gh-pages` branch.
