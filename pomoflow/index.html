📖 How to Use Pomoflow ▾
🎯 The Core Idea

Start with a 5-minute focus. Each time you complete one, the next session grows by 5 minutes. Build up to longer, deeper focus sessions over time.

✅ How It Works
  1. Tap ▶ Start to begin your first 5-min focus
  2. Stay focused — don't switch tabs or get interrupted
  3. Complete the session → earn XP, duration increases
  4. Take a short break when you need one
  5. Repeat — each session gets longer as you level up
⚠️ The Rules
  • Tab switch = Interrupt — timer resets to 5 min
  • Interrupt = +10 XP — you still earn something
  • Break = +5 XP — breaks are rewarded too
  • Streak tracks consecutive days you use Pomoflow
💡 Productivity Tips
  • Start small — the 5-min beginning is intentional
  • Single task — one focus = one task only
  • No notifications — silence your phone before starting
  • Track patterns — notice when you focus best
  • Celebrate wins — every completed session counts
  • Use sounds — ticking or soothing audio helps flow
🚫 Common Mistakes
  • Jumping to long sessions too quickly
  • Checking messages "for just a second"
  • Skipping breaks — they're part of the system
  • Perfectionism — interrupts happen, keep going
🧮 The Math

Session 1: 5 min → Session 2: 10 min → Session 3: 15 min → ... → Session 10: 50 min
10 sessions = 275 minutes (4.5 hours) of focused work!
